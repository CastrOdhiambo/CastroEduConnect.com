# CastroEduConnect 🚀

**Connecting Learners, Empowering Futures.**

A modern AI-powered Learning Management System built with Supabase.

## 🌟 Features

- **Three User Roles**: Admin, Teacher, Learner with proper permissions
- **Assessment Engine**: Multiple question types with auto-marking
- **Real-time Analytics**: Performance tracking and insights
- **Learning Resources**: Upload and manage educational content
- **Notifications**: Real-time updates and alerts
- **Dark/Light Mode**: Modern UI with theme switching
- **Mobile Responsive**: Works on all devices

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, JavaScript
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Hosting**: GitHub Pages (Frontend), Supabase (Backend)
